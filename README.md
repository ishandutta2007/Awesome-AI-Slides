## SaaS/Hosted Platforms



- **[Genspark](https://www.genspark.ai/)**  

  AI workspace with Super Agent for generating presentations, docs, and sheets from prompts. Features AI Slides with editable outputs, image generation, and multi-format export. Freemium with credit-based pricing.



- **[Beautiful.ai](https://www.beautiful.ai/)**  

  AI presentation software with DesignerBot generating decks from prompts. Smart Slides automatically adapt layout as content changes. Focus on design consistency without manual formatting.



- **[Gamma](https://gamma.app/)**  

  AI-powered presentation, document, and webpage generator. Creates polished decks from prompts or imported docs with themes, images, and layouts. Freemium with generous free tier. Popular for rapid deck creation .



- **[Tome](https://tome.app/)**  

  AI-native storytelling and presentation platform. Generates narrative-driven decks from prompts with multimedia support. Pivoted toward sales enablement use cases.



- **[Pitch](https://pitch.com/)**  

  Collaborative presentation platform with AI features including deck generation, slide rewriting, and analytics. Strong team collaboration and template library.



- **[SlidesAI](https://www.slidesai.io/)**  

  Google Slides add-on that generates presentations from text. Creates slides with content, images, and speaker notes directly within Google Workspace.



- **[Presentations.AI](https://www.presentations.ai/)**  

  AI presentation generator from prompts, documents, or YouTube videos. Features brand customization, analytics, and export to PowerPoint/Google Slides.



- **[Decktopus](https://www.decktopus.com/)**  

  AI presentation tool with form-based generation, content suggestions, and interactive elements. Includes AI image generation and voice narration.



- **[Canva AI Presentations](https://www.canva.com/)**  

  Canva's Magic Design and AI features for presentations. Generates slides from prompts, suggests layouts, and creates images. Integrated with Canva's full design ecosystem.



- **[Microsoft Copilot for PowerPoint](https://www.microsoft.com/microsoft-365)**  

  Native AI assistant in PowerPoint. Generates full presentations from prompts or documents, summarizes decks, rewrites text, and creates speaker notes. Requires Microsoft 365 Copilot license.



## Open-Source GitHub Projects



- **[Marp](https://github.com/marp-team/marp)**  

  Markdown Presentation Ecosystem (MIT). Converts Markdown into slide decks via CLI, VS Code extension, or web tools. Features multiple themes, custom CSS, presenter notes, and export to PDF/PPTX/HTML. 8k+ GitHub stars. The most widely adopted open-source Markdown-to-slides tool .



- **[Slidev](https://github.com/slidevjs/slidev)**  

  Presentation slides for developers (MIT). Built on Vue and Vite with Markdown authoring. Features code highlighting, live coding, animations, presenter mode, LaTeX support, diagrams (Mermaid), and PDF/PNG/PPTX export. 35k+ GitHub stars. Rich interactive capabilities .



- **[reveal.js](https://github.com/hakimel/reveal.js)**  

  HTML presentation framework (MIT). Create slides using HTML/Markdown with nested slides, speaker notes, PDF export, and extensive plugin ecosystem. 68k+ GitHub stars. The foundation for many web-based presentation tools .



- **[Impress.js](https://github.com/impress/impress.js)**  

  JavaScript presentation framework based on CSS3 transforms (MIT). Creates 3D spatial presentations with zoom, rotation, and pan. 37k+ GitHub stars. More artistic than linear slide tools .



- **[Remark](https://github.com/gnab/remark)**  

  Simple, in-browser Markdown presentation tool (MIT). Converts Markdown to slides with speaker notes and syntax highlighting. 12k+ GitHub stars. Lightweight and easy to host .



- **[Spectacle](https://github.com/FormidableLabs/spectacle)**  

  React-based presentation library (MIT). Build decks as React components with JSX. Features animations, code highlighting, and presenter mode. 9k+ GitHub stars .



- **[mdx-deck](https://github.com/jxnblk/mdx-deck)**  

  MDX-based presentation decks (MIT). Write slides in MDX with React components. Features themes, presenter mode, and PDF export. 11k+ GitHub stars .



- **[WebSlides](https://github.com/webslides/WebSlides)**  

  HTML/CSS presentation framework (MIT). Create beautiful slides with semantic HTML and CSS. 6k+ GitHub stars. Focus on design and simplicity .



- **[Landslide](https://github.com/adamzap/landslide)**  

  Python-based slide generator (Apache-2.0). Creates HTML5 presentations from Markdown or reStructuredText. Supports PDF/PNG/PPTX export .



- **[Hovercraft](https://github.com/regebro/hovercraft)**  

  Python tool for impress.js presentations from reStructuredText (MIT). Generates 3D animated slides with speaker notes .



- **[Pandoc](https://github.com/jgm/pandoc)**  

  Universal document converter (GPL-2.0). Converts Markdown to PowerPoint (pptx), Beamer (PDF), reveal.js, and more. 35k+ GitHub stars. The Swiss Army knife of document conversion .



### Additional Strong Open-Source Options



- **[Slidev Themes](https://github.com/slidevjs/themes)** — Community themes for Slidev presentations.

- **[Marp CLI](https://github.com/marp-team/marp-cli)** — Command-line interface for Marp with PDF/PPTX/HTML export.

- **[Vite Slidev Starter](https://github.com/slidevjs/slidev)** — Starter templates for Slidev decks.

- **[HTML Slidy](https://www.w3.org/Talks/Tools/Slidy2/)** — W3C's accessible HTML slide format.

- **[DZSlides](https://github.com/paulrouget/dzslides)** — Minimal HTML5 slide template.

- **[Quarto](https://github.com/quarto-dev/quarto-cli)** — Scientific publishing system (GPL-2.0) with Reveal.js presentation support.

- Community **n8n** workflows for AI-generated slide content pipelines.



**Frameworks for building custom systems**: Combine **Slidev** or **Marp** as the Markdown-to-slides engine with **reveal.js** for web-based presentations, **Pandoc** for format conversion, **Quarto** for scientific decks, and **LLM APIs** for content generation—creating a fully self-hosted, enterprise-grade AI slide platform.
